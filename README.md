# Social Studies Key Terms

A bilingual classroom review website with English and Traditional Chinese key-term definitions, flashcards, list view, and a matching game for Grades 7–10.

## Publish with Vercel

This is a static site and needs no build command.

- Framework preset: Other
- Root directory: repository root
- Build command: leave empty
- Output directory: leave empty

After the GitHub repository is imported into Vercel, every commit to the main branch creates a new production deployment.

## Local preview

Open `index.html` directly, or serve this directory with any static web server.

## Future services

Supabase can later provide authentication, saved student progress, teacher-created sets, and database storage. AWS S3 and CloudFront are optional for a much larger image library. Keep all privileged keys out of this repository and configure them through Vercel environment variables.
